# 战斗技能威力曲线与暴击伤害设计

## 背景

当前伤害公式以 `sqrt(skillPower * 2)` 计算技能威力基值，导致高威力技能相对普攻的成长过缓。以威力 80 的普攻为基准，威力 300 的“永恒之枪”理论倍率仅约 1.94 倍；物理强化类被动同时作用于两者，因此不会改善技能与普攻之间的差距。此外，暴击目前只提供 Press Turn 半图标收益，没有伤害倍率。

## 目标

- 保持威力 80 普攻的现有绝对伤害基准。
- 令威力 300 技能在相同攻防、等级、属性相性与被动条件下达到约 3 倍普攻伤害。
- 玩家和敌人共用同一条威力曲线，使高威力 Boss 技能同步获得威胁提升。
- 暴击造成 1.5 倍最终伤害，并保留现有 Press Turn 奖励。

## 威力曲线

采用以威力 80 为锚点的分段函数：

```text
power <= 80:
  base = sqrt(power * 2)

power > 80:
  base = sqrt(80 * 2) * (power / 80) ^ 0.83
```

参数由 `formulas.jsonl` 提供：

- `powerReference = 80`
- `powerExponent = 0.83`

相对威力 80 的预期倍率：

| 威力 | 倍率 |
|---:|---:|
| 80 | 1.00 |
| 100 | 1.20 |
| 150 | 1.68 |
| 200 | 2.14 |
| 300 | 3.00 |
| 500 | 4.59 |
| 700 | 6.06 |

威力不超过 80 时沿用原平方根曲线，以避免低威力、多段技能和普攻基准发生突变。威力超过 80 时使用幂指数曲线，增强高威力技能的资源投入回报。

## 暴击伤害

`critRate.damageMultiplier = 1.5`。命中被判定为暴击后，对已经经过蓄力、被动增伤和防御减伤处理的整数伤害应用倍率并向下取整。暴击标签与 Press Turn 结算规则保持不变。

## 保持不变的规则

- 攻防比指数 `statRatioExponent = 0.75`。
- 等级影响、属性相性、随机浮动和最小伤害。
- 物理强化与高级物理强化的现有乘算叠加方式。
- 挑战 Boss 的技能威力数据，不进行同步下调。

## 验证

- 单元测试固定随机浮动，验证威力 80 锚点和 100/150/200/300/500/700 的倍率。
- 单元测试验证相同攻击结果在暴击时为普通伤害的 1.5 倍，并仍带有 `critical` 标签。
- 内容注册测试覆盖新增公式字段。
- 运行战斗窄测试、完整测试、lint 和生产构建。
